# 📑 Repositório de Aulas - 1º Termo 

Este repositório armazena os códigos e projetos práticos desenvolvidos durante as aulas do curso técnico em Desenvolvimento de Sistemas.

---

## 📂 Estrutura de Organização

Os projetos estão organizados em pastas individuais nomeadas com a data da aula e o tema abordado, seguindo o padrão:
`[ANO][MÊS][DIA]_[NOME_DO_PROJETO]`

Cada pasta contém um projeto completo configurado no ambiente **VS Code com PlatformIO**, pronto para ser aberto e compilado.
